# OpenContainer Error Reference

> Generated from docs/api/ERROR-CATALOG.v0.1.json. Do not edit this file by hand.

Errors are stable machine codes. Consumer UI may translate the prose, but branching/recovery logic should use error.code.

| Code | Compatibility class | Cause | Consequence | Recovery |
| --- | --- | --- | --- | --- |
| OC_INVALID_STATE | caller-state | The requested operation is not valid in the runtime's current lifecycle or configuration state. | The operation is rejected without changing the requested state. | Check runtime state/configuration, complete required setup, then retry. |
| OC_INVALID_ARGUMENT | caller-error | A caller supplied an argument outside the accepted shape or range. | The operation is rejected before applying the invalid request. | Validate the documented argument contract and retry. |
| OC_PATH_ESCAPE | security-boundary | A guest path would resolve outside /workspace. | Filesystem access is denied; no escaped path is opened or created. | Keep guest paths inside /workspace and avoid parent traversal outside the workspace. |
| OC_INTERNAL_PATH | security-boundary | Guest code attempted to access a trusted internal filesystem namespace. | Access to the internal namespace is denied. | Use public workspace paths or the documented SDK instead of internal paths. |
| OC_STALE_GENERATION | stale-generation | A transaction or receipt targets an older VFS/publication generation. | The stale mutation or action is rejected to prevent overwriting newer state. | Re-read current state, create a fresh transaction/receipt, and retry. |
| OC_NOT_FOUND | caller-state | A requested path, snapshot, route, package object, or other named resource does not exist. | The requested operation cannot continue against the missing resource. | Verify the identifier/path or create/restore the resource first. |
| OC_NOT_DIRECTORY | filesystem-boundary | An operation requiring a directory encountered a non-directory entry. | Directory traversal or mutation is rejected. | Use a directory path or correct the workspace layout. |
| OC_IS_DIRECTORY | filesystem-boundary | A file operation targeted a directory. | The file operation is rejected. | Target a file path or use the corresponding directory operation. |
| OC_RESOURCE_EXHAUSTED | resource-limit | A configured quota, lease, capacity preflight, or browser storage budget is exhausted. | The resource-consuming operation fails closed; canonical state is not intentionally advanced. | Release resources, reduce workload, export/GC data, or increase an applicable product budget before retrying. |
| OC_OUTPUT_LIMIT | resource-limit | A virtual process exceeded its bounded output budget. | Further output is rejected and the process may exit with failure. | Reduce output volume, stream/aggregate results, or configure a safe larger process output budget. |
| OC_COMMAND_NOT_FOUND | caller-state | No registered virtual command matches the requested command name. | No process handler is executed. | Register/bind the command or use a supported package command. |
| OC_NETWORK_DENIED | security-boundary | Guest code requested a network capability outside the authorized policy. | The network request/socket/channel is denied. | Use an explicitly authorized fetch/virtual HTTP route or redesign around supported browser network capabilities. |
| OC_PREVIEW_STALE | stale-generation | A preview request carries a stale epoch or owner proof. | The stale preview route is rejected instead of reaching a newer owner. | Refresh the preview receipt/URL from the current route publication. |
| OC_TOOLCHAIN_UNSUPPORTED | unsupported-compatibility | The requested toolchain/artifact/profile is outside the retained browser-native compatibility profile. | Toolchain execution is refused. | Use the pinned supported toolchain profile or add a separately evidenced profile. |
| OC_TOOLCHAIN_SKEW | artifact-integrity | Toolchain JS/binding/artifact versions do not match the frozen identity. | Execution is blocked to avoid undefined mixed-version behavior. | Install/use the exact coherent toolchain versions recorded by the production profile. |
| OC_DIGEST_MISMATCH | artifact-integrity | Fetched or persisted bytes do not match the expected cryptographic digest. | The artifact/content is rejected and not trusted. | Refetch from the authoritative source, verify lockfile/SRI metadata, or repair corrupted persistence. |
| OC_BUILTIN_UNAVAILABLE | unsupported-compatibility | A Node builtin surface has no supported browser adapter in the active profile. | The builtin import/call cannot be provided. | Use a supported adapter or redesign around browser-native/public OpenContainer capabilities. |
| OC_REQUIRE_ESM_UNSUPPORTED | package-resolution | CommonJS require() attempted to synchronously load an ESM-only target. | The module is not synchronously executed. | Use ESM import(), an import condition, or a package entry compatible with require(). |
| OC_MODULE_EXECUTION_DISABLED | security-boundary | A module execution path is disabled by the active security or runtime profile. | The module is resolved but not executed through that path. | Use the allowed execution authority/profile or enable a separately reviewed capability. |
| OC_ESM_PUBLICATION_INVALID | deployment-runtime | A native-ESM publication request/session/module identity is invalid. | The module is not published into the browser ESM edge. | Recreate the publication with valid workspace paths/session identity and retry. |
| OC_ESM_IMPORT_PHASE_UNSUPPORTED | unsupported-compatibility | The module uses an import phase/syntax not supported by the current publication pipeline. | Publication/execution stops rather than rewriting unsupported semantics. | Refactor to supported ESM syntax or wait for a profile that explicitly supports that import phase. |
| OC_ESM_DYNAMIC_IMPORT_UNRESOLVED | package-resolution | A dynamic import cannot be resolved deterministically by the publication graph. | The unresolved dynamic import is not published/executed. | Use a resolvable literal/specifier pattern or explicitly include the target in the supported graph. |
| OC_ESM_EDGE_UNAVAILABLE | deployment-runtime | The browser Service Worker/module edge is unavailable, uncontrolled, or timed out. | Native ESM browser execution cannot proceed safely. | Check hosting headers/Service Worker lifecycle, reload a compatible controller, and rerun the browser self-check. |
| OC_SERVICE_WORKER_INCOMPATIBLE | storage-compatibility | The candidate/controller Service Worker compatibility profile differs from the runtime profile. | Activation/claim/reuse is rejected. | Serve the matching Service Worker/runtime release pair; do not force activation across incompatible profiles. |
| OC_STORAGE_MIGRATION_INVALID | storage-compatibility | A storage migration/rollback envelope, phase, version transition, validation, or payload is unsafe/invalid. | Migration or writable open is refused; recovery roots remain authoritative. | Use an adjacent supported migration, repair/restore valid storage, or open a supported read-only/export path. |
| OC_STORAGE_READ_ONLY | storage-compatibility | A rolled-back/compatibility runtime attempted to mutate storage that is intentionally read-only. | The write is rejected while readable data remains available. | Export data, upgrade to a compatible writer, or migrate with the supported release path before writing. |
| OC_GUEST_WORKER_FAILED | worker-lifecycle | An isolated guest Worker failed during startup, RPC, import, execution, or termination. | Guest execution fails without granting extra authority. | Inspect the stable error/details and diagnostics; correct guest code/capabilities and retry in a fresh worker. |
| OC_MODULE_NOT_FOUND | package-resolution | The module resolver cannot find the requested package/module from the importer graph. | Module loading stops. | Install/mount the dependency under the frozen package graph or correct the specifier/importer. |
| OC_INVALID_MODULE_SPECIFIER | package-resolution | A module specifier is syntactically invalid for the supported resolver. | Resolution stops before loading a target. | Use a valid relative, absolute-workspace, package, imports, or supported URL-like specifier. |
| OC_INVALID_PACKAGE_CONFIG | package-resolution | A package.json/package metadata shape used for resolution is invalid. | Package resolution/loading for that package is refused. | Fix the package metadata/exports/imports configuration and freeze it in the package graph. |
| OC_INVALID_PACKAGE_TARGET | security-boundary | An exports/imports target violates the supported package target rules. | Resolution is rejected before escaping or loading an invalid target. | Correct the package target to a valid in-package/supported target. |
| OC_PACKAGE_CONTENT_MISSING | package-resolution | Frozen package metadata references immutable content that is not available from persistence or authorized fetch. | The package cannot be mounted/installed from missing bytes. | Allow one authoritative refetch/repersist or restore the pinned content store. |
| OC_PACKAGE_PATH_NOT_EXPORTED | package-resolution | A consumer requested a package subpath not exposed by package exports. | Resolution is denied according to package exports. | Import an exported subpath or update the package's documented exports in a new package version. |
| OC_PACKAGE_IMPORT_NOT_DEFINED | package-resolution | A package #imports specifier is not defined for the current package/conditions. | Resolution fails. | Declare the imports mapping or use an existing public/internal package specifier. |
| OC_UNSUPPORTED_DIRECTORY_IMPORT | package-resolution | ESM resolution targeted a directory where directory import is not supported. | Resolution stops instead of applying non-Node/browser-specific guessing. | Import an explicit file or exported package entry. |
| OC_NATIVE_ADDON_UNSUPPORTED | unsupported-compatibility | A package/module requires a native .node addon or host-native execution. | The native addon is not loaded in the browser runtime. | Use a WASM/pure-JS/browser-native alternative or move that capability outside OpenContainer Core. |
| OC_ARTIFACT_INTEGRITY | artifact-integrity | A retained/downloaded artifact fails identity, integrity, or metadata validation. | The artifact is rejected before execution. | Restore the pinned artifact from its authoritative source and verify digest/version metadata. |
| OC_ARTIFACT_TOO_LARGE | resource-limit | An artifact/archive exceeds a configured safety size budget. | Download/extraction/ingest is refused. | Use a smaller artifact, split content, or change a reviewed resource budget. |
| OC_ARCHIVE_UNSAFE | security-boundary | An archive contains unsafe paths/entries or violates extraction policy. | Extraction is aborted without intentionally writing unsafe content. | Rebuild the archive without path traversal, unsafe links, or forbidden entries. |
| OC_WORKER_TIMEOUT | worker-lifecycle | A Worker/RPC operation exceeded its bounded deadline. | The operation fails and the Worker may be terminated/reclaimed. | Reduce/blocking work, inspect deadlock/RPC state, or retry in a fresh worker within supported limits. |
| OC_WORKER_STALE | stale-generation | A Worker message/result belongs to a stale epoch/session. | The stale result is ignored/rejected. | Use the current Worker/publication receipt and discard results from terminated/restarted sessions. |
| OC_WORKER_CLOSED | worker-lifecycle | A caller used a Worker authority after it was closed/terminated. | The request is rejected; the closed worker is not resurrected. | Start a new Worker authority/session before executing more guest work. |
| OC_IMPORT_INVALID | data-format | Portable snapshot/import bytes or rows do not match the supported format. | Import is rejected rather than partially restoring invalid data. | Use a valid OpenContainer NDJSON export for the supported format version or restore a known-good backup. |
