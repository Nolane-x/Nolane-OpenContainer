# ADR-003 — Implementation evidence cannot inherit research promotion

**Status:** Accepted.

Research receipts define target identities and tests, but product code receives no browser/integration/release promotion merely because a prior harness or external implementation passed.

In particular, `lightningcss-wasm@1.33.0` remains at external artifact-identity concordance until exact bytes are locally retained and differentially executed. Vite C1 and C2 remain open until OpenContainer itself runs them.
