# Code of Conduct

OpenContainer contributors and maintainers are expected to keep technical collaboration respectful, focused and safe.

Harassment, threats, discriminatory abuse, doxxing, deliberate disclosure of another person's private data, and retaliation for good-faith security reporting are not acceptable. Technical disagreement is welcome; personal attacks are not.

Maintainers may edit, hide or remove disruptive material and may restrict participation when needed to protect contributors or the project. Security reports should follow `SECURITY.md`, not public discussion threads.

This project is currently small and pre-1.0. Enforcement responsibility rests with the repository owner/maintainers identified by project governance. Serious conduct issues involving a maintainer should be escalated to another maintainer when one exists; if no independent maintainer exists, broad external contribution remains fail-closed rather than pretending an independent appeals body exists.
