OpenContainer P3 Native Picker Permission Court

This manual court exercises a real user-selected FileSystemDirectoryHandle. It never records the selected directory name or path.

1. Select and prepare

Select a disposable test folder. OpenContainer will create one file named opencontainer-p3-native-picker-court.txt and save a local OPFS recovery copy.

2. Prove external edit conflict

After preparation, edit opencontainer-p3-native-picker-court.txt outside this page using your OS/editor, then click verify. The court must detect the revision change before overwrite.

3. Revoke native folder permission

Use Chrome's site/file permission controls to revoke this site's access to the selected folder. Do not grant permission again. Then select how you revoked it and verify.

4. Evidence receipt

PASS requires: real picker handle, initial readwrite grant, external edit conflict blocked, native permission transition away from granted, privileged write blocked after revocation, and local OPFS recovery still readable.
